# what we're building

We don't just learn to code — we ship real products. Every semester, club members collaborate on projects that solve actual problems for our campus community.

From web applications to mobile apps, Discord bots to CLI tools, our projects span multiple tech stacks and skill levels. Whether you're a first-year exploring your first programming language or a senior building your portfolio, there's always something to contribute to.

Current active projects include our club website (the one you're looking at!), an attendance tracking system for events, and a CodeBuddy Discord bot that helps members find pair programming partners. All projects are open source and contributions are welcome.

$ start contributing

Contributing to SRCC projects is the fastest way to level up your skills. We maintain beginner-friendly issues specifically for newcomers.

Every project has "good first issue" labels for tasks that are perfect for first-time contributors. These might include fixing a small bug, adding a new feature, writing documentation, or improving tests. Senior members are always available to review your code and help you learn.

The process is simple: pick an issue, fork the repo, make your changes, and submit a pull request. We'll walk you through every step if it's your first time. Most members ship their first contribution within a week of joining.

git clone Fork & clone the repo
git branch Create a feature branch
git push Submit your PR
